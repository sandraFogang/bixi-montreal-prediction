# Données

## BIXI.RData

Données de départs journaliers BIXI Montréal (avril – octobre 2019).

Le fichier contient deux objets R :

| Objet | Description |
|-------|-------------|
| `Bixi_data` | Départs journaliers pour 587 stations sur 196 jours + 17 prédicteurs (12 spatiaux, 5 temporels). Normalisés entre 0 et 1. |
| `Spatial_positions` | Coordonnées GPS (latitude, longitude) des 587 stations. |

**Source :** BIXI Montréal — https://bixi.com/fr/donnees-ouvertes
